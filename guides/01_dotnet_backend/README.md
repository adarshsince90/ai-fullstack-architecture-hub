# Domain 1: Backend & .NET Core

Welcome to the **Backend & .NET Core** domain guide. This module covers essential principles, runtime internals, and high-performance patterns in modern .NET (8 & 10), C#, ASP.NET Core Web API, Entity Framework Core, asynchronous concurrency, and real-time distributed communication.

---

## 🗺️ Domain Mind Map & Subtopics

```text
Backend & .NET Core
 ├── 1. C# 12/13 Internals & CLR Runtime (Memory, GC, Span<T>, Value vs Reference Types)
 ├── 2. ASP.NET Core Web API Architecture (Kestrel, Middleware Pipeline, DI Lifetimes)
 ├── 3. Entity Framework Core & Query Tuning (IQueryable, Execution Plans, N+1 Prevention)
 ├── 4. Async/Await, Concurrency & Background Services (SynchronizationContext, Channels)
 └── 5. Real-Time & High-Throughput RPC (gRPC Protobuf vs REST vs SignalR WebSockets)
```

## 📚 Detailed Guides

1. [01_csharp_internals.md](./guides/01_dotnet_backend/01_csharp_internals.md)
   - CLR execution pipeline, JIT compilation, Garbage Collection generations (Gen 0, 1, 2, LOH, POH).
   - Memory management: Stack vs Heap, `ref struct`, `Span<T>`, and `Memory<T>`.

2. [02_aspnetcore_webapi.md](./guides/01_dotnet_backend/02_aspnetcore_webapi.md)
   - Kestrel web server mechanics and reverse proxy setups.
   - Middleware pipeline execution order, Exception Handling Middleware, and Custom Action Filters.
   - Dependency Injection lifetimes (`Transient`, `Scoped`, `Singleton`) and anti-patterns (Captive Dependencies).

3. [03_efcore_optimization.md](./guides/01_dotnet_backend/03_efcore_optimization.md)
   - `IQueryable<T>` deferred execution vs `IEnumerable<T>`.
   - AsNoTracking, Split Queries (`AsSplitQuery`), Compiled Queries, and Indexing alignment.

4. [04_async_threading.md](./guides/01_dotnet_backend/04_async_threading.md)
   - `async` / `await` state machines generated by the C# compiler.
   - `Task.WhenAll`, `Task.WhenAny`, `ValueTask<T>`, `IAsyncEnumerable<T>`.
   - `IHostedService`, `BackgroundService`, and `System.Threading.Channels` for producer-consumer pipelines.

5. [05_grpc_signalr.md](./guides/01_dotnet_backend/05_grpc_signalr.md)
   - HTTP/2 multiplexing, Protocol Buffers binary serialization, gRPC streaming modes.
   - SignalR WebSockets, Server-Sent Events (SSE), Long Polling fallback, Redis backplane for scaling hubs.
