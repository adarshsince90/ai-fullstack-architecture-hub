Failure Mode & Resiliency
If Redis master crashes, Sentinel promotes replica in <3s. Idempotency keys prevent duplicate deductions.
Why Naive Check-Then-Set Fails: If Thread A and Thread B both read stock = 1 at the same microsecond, both deduct 1, resulting in stock = -1 (Overselling!). Redis executes Lua scripts as a single atomic instruction on its single-threaded event loop. 
-- Keys: KEYS[1] = inventory_key, KEYS[2] = user_order_set
-- Args: ARGV[1] = user_id, ARGV[2] = requested_qty
local current_stock = tonumber(redis.call('GET', KEYS[1]) or 0)
if current_stock < tonumber(ARGV[2]) then
    return -1 -- Error: Sold Out / Insufficient Stock
end

-- Check if user already purchased (Prevent duplicate orders)
if redis.call('SISMEMBER', KEYS[2], ARGV[1]) == 1 then
    return -2 -- Error: User already ordered
end

-- Atomically deduct stock and record user in order set
redis.call('DECRBY', KEYS[1], ARGV[2])
redis.call('SADD', KEYS[2], ARGV[1])
return 1 -- Success: Stock Reserved!

Failure Mode & Resiliency
If Raft Leader scheduler node crashes, secondary replica wins election lease and reloads Time Wheel in <1s.
Why DB Polling Fails (SELECT * WHERE run_at <= NOW()): Polling causes massive DB table scans and index contention at millions of rows.
Hierarchical Time Wheel (Kafka / Netty Pattern):
  • Second Wheel: 60 slots (1 second per slot). Ticks every 1,000ms.
  • Minute Wheel: 60 slots (1 minute per slot). When second wheel wraps, minute wheel advances 1 slot and cascades tasks down to second wheel.
  • Time Complexity: $O(1)$ task insertion, $O(1)$ task cancellation, and $O(1)$ per-tick trigger execution!

Protocol Payload Sample

Failure Mode & Resiliency
Spider traps (infinite circular paths) are detected by maximum crawl depth limits and URL length filters.
Key Crawler Bottlenecks & Design Solutions:
  • Politeness Guarantee: Mercator Frontier model uses two sets of queues: Priority Queues (PageRank/Freshness) and Politeness Queues (one per domain with delay timer, e.g., $\ge 1\text{s}$ between requests to same domain).
  • URL Deduplication: Redis Bloom Filter with 10 Billion URL capacity ($\sim 12\text{ GB}$ RAM at $0.1\%$ false positive rate) avoids crawling previously seen URLs.
  • Content Deduplication (SimHash): Computes 64-bit fingerprint of webpage text tokens. Pages with Hamming distance $\le 3$ are discarded as near-duplicates (mirrors, spam).

Failure Mode & Resiliency
If primary database fails, read replicas continue serving redirects uninterrupted (Read-heavy resilience).
Why Not MD5/SHA256 Hash Truncation? Truncating a hash introduces hash collisions that require database lookup loops and retry penalties.
Key Generation Service (KGS) Pattern:
  • KGS generates unique integer IDs via distributed range allocation (e.g. Server 1 gets 1-1,000,000, Server 2 gets 1,000,001-2,000,000).
  • Converts ID into Base62 string (0-9, a-z, A-Z). ID 125 $\rightarrow$ '21', ID 987654321 $\rightarrow$ '14q2P9'.
  • HTTP 301 vs 302: 301 Permanent Redirect reduces server load (browser caches redirect), while 302 Temporary Redirect enables click tracking and analytics.
